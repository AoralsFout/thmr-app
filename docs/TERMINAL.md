# THMR 终端客户端

CLI、TUI 与 Flutter 桌面界面共享 `thmrd` 播放宿主，支持免登录直播、来源、码率、音量和状态查询。

## 安装

解压后保留完整目录。独立终端包将 `bin` 加入 PATH；完整桌面包的命令位置如下：

| 平台 | CLI 位置 | 运行要求 |
| --- | --- | --- |
| Windows | `thmr.exe` | 保留同目录的 `thmrd.exe` 和 `libmpv-2.dll` |
| Linux | `bundle/thmr` | Ubuntu 24.04/glibc 2.39 基线，系统提供 `libmpv2`；MPRIS 需要用户 D-Bus 会话 |
| macOS | `THMR.app/Contents/Helpers/thmr` | 独立终端包需保留 `THMRHost.app`；公开分发需 Developer ID 与公证，预览包可采用本地签名 |

Linux 完整包可直接运行 `./thmr`，或将 `bundle` 的绝对路径加入 PATH。`thmr gui` 通过 `thmr-gui` 检查运行库并打开图形界面；应用菜单使用相同命令。

## 命令

```text
thmr                   交互终端进入 TUI，或使用 defaultUi 设置
thmr tui               打开终端界面
thmr gui               打开已安装的兼容 Flutter 界面
thmr play              后台收听，必要时启动宿主
thmr pause             暂停并停止拉流
thmr stop              停止收听，保留宿主
thmr toggle            切换播放/暂停
thmr volume 35         修改 THMR 音量，范围 0–100
thmr source auto       自动选择来源，也可用 source1/source2
thmr quality 128k      选择状态接口公开的启用码率
thmr status --json     查询状态，不自动启动宿主
thmr refresh           刷新曲目信息
thmr doctor            检查安装与音频依赖
thmr paths --json      查看运行与配置目录
thmr daemon start      启动宿主
thmr daemon stop       停止播放并关闭宿主
```

无参数启动需要交互终端；脚本中应显式指定子命令。完整参数见 `thmr --help`。

TUI 使用“幻想乡信号站”布局：宽窗口显示左侧排播与右侧曲目与整面弹幕舞台，窄窗口自动纵向排列。鼠标点击控件和排播曲目，滚轮在排播区域浏览；音量使用降低/提高按钮，每次 2%，没有拖动操作。排播只读，选中后显示摘要，`Enter` 或“详情”查看完整信息。

排播首行显示当前曲目，用单色 `♪` 标识，后续曲目从 `01` 开始编号。动态模式播放时音符始终可见，青色亮度以 1.2 秒为周期平滑起伏，最低保留 65% 亮度；曲名和选中背景保持不变。暂停、静音、主机断连、静态模式或打开弹层时保持固定亮度。浏览选中的箭头独立显示；基础字符模式使用 `*` 代替音符。

| 按键 | 操作 |
| --- | --- |
| `Tab` / `Shift+Tab` | 切换焦点，`Enter` 激活控件 |
| 空格 / `s` | 播放或暂停 / 停止 |
| `+` / `-` | 调音量，每次 2% |
| `↑↓` / `j k` | 浏览排播 |
| `PageUp` / `PageDown`，`Home` / `End` | 翻页、首尾 |
| `1` / `2` / `a` | 选择音源 1、2、自动 |
| `b` / `r` | 切换可用码率 / 刷新排播 |
| `i` | 查看正在放送的曲目信息，也可点击当前曲名 |
| `m` | 切换动态 / 静态动效 |
| `x` | 切换基础绘图字符，适配不支持 Braille 的终端 |
| `?` / `Esc` | 帮助 / 关闭弹层 |
| `q` / `Ctrl+C` | 离开界面并保留后台播放 |

默认使用动态档：右侧为弹幕舞台，曲目文字覆盖在弹幕之上。频谱与峰值作为独立区域放在底栏：有足够宽度时位于控制区右侧，分界线与上方排播列表/舞台的实际分界线对齐，包含 L/R 电平栏出现或隐藏造成的偏移；对齐后控制区不足 38 列或频谱不足 40 列时，频谱移到控制区下方；高度不足时压缩频谱高度。频谱顶部显示频率范围和构图名称，最底部保留提示文字。静态档关闭频谱。8 种敌机队形（交错、游走、环绕、八字、摆阵、纵向入场、主机与卫星、两翼）与 12 种弹幕构图独立组合，包括扇面、螺旋、花轮、多边形、交织波纹、帘幕、缺口环、切线、雁形、双环回声、十字与抛物线喷泉。队形约持续 9–18 秒，弹幕乐句约持续 3.2–7.5 秒，尽量在音乐重拍换段；两条时间线各自推进，旧弹幕继续飞行后自然消散。

空间足够时，舞台底部显示 `AUDIO` 指标：`LVL` 电平、`INT` 输入强度、`DRV` 舞台平滑后的实际驱动强度、`LO/MID/HI` 低/中/高频、`BP` 拍长（秒）、`BC` 节拍置信度、`BT` 重拍计数、`ACC` 高频瞬态计数、`SRG` 渐强计数。小数保留三位，数值来自舞台最近一次实际执行的模拟步。`LIVE` 表示实时，`WAIT` 表示等待指标，`STATIC` 表示静态档不使用音频指标；`HOLD:STOP/MUTE/LINK/STALE/MODAL` 分别表示因未播放、静音、断连、指标不可用或弹层而冻结，保留最后使用值。指标按窗口宽度换行，窗口过矮时隐藏，保留曲名与舞台空间。

`AUDIO` 上方显示青色 `WAVE` 波形，通常占三行；窗口过矮时缩成一至两行或隐藏，静态档隐藏。波形来自同一份播放 PCM 的最近 2048 个采样，每段保留双声道的最小/最大值，围绕零中线绘制，避免反相声道相消。它与频谱共用宿主播放时钟，不建立额外的电台连接；显示的是源音频幅度，范围固定为 -1 至 1。暂停、静音、断连、数据过期或弹层打开时保留最后一帧，新音频代次会清除旧波形；基础字符模式使用 ASCII 绘制。升级后须重启播放宿主才能提供波形；旧宿主仍可播放和显示频谱，波形显示 `WAVE WAIT`。

发射节奏包括连续、错拍、短连射、问答和切分。重拍由部分敌机领奏，高频瞬态做短促插入；低/高频占比影响构图选择，中频与相对能量影响移动速度和疏密，渐强可提前变奏。最近 2 种队形、3 种主构图和 16 套弹幕组合会避开重用，旋向、臂数、间距、速度、转向和停驻点也会变化。每次启动生成会话种子，并结合曲目生成演出；固定种子可在测试中重现，正常播放不再从固定四段顺序开场。

弹体包括圆弹、针弹、花瓣、米粒、旋转星芒、空心圆环、加速苦无和游动蝶弹，均可参与不同构图。弹体以独立相位轻微明暗起伏，保留至少 83% 亮度；静态档关闭闪烁，暂停、静音和详情弹层会一起冻结。光束采用停驻攻击：敌机从 0.75 秒蓄力预告开始，到发射与收束结束（合计约 1.95 秒）保持在原地，并暂停该敌机的常规弹幕发射。其他敌机继续行动；攻击结束后从暂停的自身轨迹进度接续，用约 0.35 秒恢复移动速度。光束起点固定在停驻位置，扫射方向与组合联动。换波会等待停驻敌机恢复并走完轨迹，因此队形时长可适当顺延；临近原定退场时不再开始新一轮光束。固定步长模拟，目标约 30 FPS，最多 2400 颗子弹与 6 道光束；接近上限时减少常规发射，让密集段自然回落。此为原创东方风格编排，尚未逐关复刻原作脚本。

主区域最左侧在终端至少 110 列、25 行时显示 L/R 双声道竖直电平条，空间不足时自动隐藏。电平取自宿主实际播放的同一份 PCM，显示源音频的 RMS 电平、峰值保持与 -60 至 0 dBFS 刻度，不计播放音量和系统混音增益；单声道同时显示在 L/R。暂停、静音或分析数据过期时电平回落，静态档归零。

静态档保留固定花瓣弹幕构图，关闭本地指标订阅与持续动画。暂停、静音、断流或打开帮助/详情时弹幕冻结；恢复后不补发冻结期间的音频事件。暂停或断流后频谱回落。动效与绘图字符偏好保存到配置目录的 `tui.json`，旧的 `standard` / `fancy` 自动映射为 `dynamic`，`static` 保持静态。

播放宿主通过内置 minimp3 将当前电台 MP3 流解码一次，同一份 PCM 同时用于播放和提前分析。左右声道分别计算 2048 点 FFT 后平均能量，避免反相信号相消；单声道复用一次 FFT。弹幕特征始终取 40 Hz 至 16 kHz（不超过采样率一半）的固定 48 个对数频带。指标附带音频样本位置，宿主按实际播放时钟发布到期指标，提前量最多约 3 秒，消费后回收；TUI 只接收本地指标，不下载或解码电台音频。

频谱显示另用稳定的自适应频段：持续约 10 秒确认丰富音频的高频边界较低后，缓慢收缩显示上限；有真实高频持续出现约 0.12 秒后较快展开。上限保留余量并按 500 Hz 取整，最低 4 kHz（低采样率以实际可用范围为准）。静音、底噪和单音不触发收缩，短暂独奏不会立即改变范围。频谱标题显示当前实际范围；缩放时已有柱形与峰值轨迹按真实频率重映射。显示端最多施加 3 dB 的高频抬升，并保留噪声门限；真实为零的频带保持为零，这些显示处理不反馈到弹幕的高频判断中。

播放和分析共用一条上游流连接；自动选择音源或显式测速仍可能短暂建立独立的匿名探测请求。指标通过经过鉴权的本地 WebSocket 传输，没有外部 FFT 工具或音频设备采集依赖。静态档、暂停、主机断线或退出 TUI 时取消本地指标订阅。宿主播放重连、来源切换和码率切换都会清除旧指标、建立新音频代次；暂停停止下载，恢复时重新加入直播位置。403/429 至少等待 60 秒，并遵守 `Retry-After`。指标不可用时显示提示，旧宿主会提示重启或升级；不会退回第二条电台连接。共享播放时钟避免了原先两条链路独立缓冲和调度造成的持续错位；FFT 窗口、指标传输和终端绘制仍有延迟。

可用 `THMR_TUI_ASCII=1` 初始采用基础绘图字符，`THMR_TUI_REDUCED_MOTION=1` 初始采用静态档。推荐使用支持真彩色、中文等宽字符的终端。

直播不支持点播、seek 或本地跳歌，恢复播放时连接当前广播位置。

GUI 明确退出会先请求停止播放并关闭宿主。后台服务不可达或 2 秒内未确认时，客户端仍会关闭并释放本机连接；后台故障不会阻止退出。最小化到托盘/任务栏继续播放。

## 设置与升级

`thmr paths` 显示用户目录，偏好保存在配置目录的 `settings.toml`。例如 `defaultUi = "gui"` 可调整交互终端无参数启动的默认界面。GUI 主题与窗口设置仍由图形客户端保存。

独立终端包可用 `THMR_GUI_PATH` 或设置中的 `guiPath` 指定兼容 GUI。开发用环境变量与构建步骤见源码仓库的 `docs/DEVELOPMENT.md`。

升级前执行 `thmr daemon stop` 并关闭 TUI。完整桌面包使用 GUI 自更新；独立终端包当前手动替换完整目录。首次从 0.1.x 桌面版切换时先退出旧 GUI，重新确认音量、来源和码率；旧播放设置尚未自动迁移。

宿主启动失败时，CLI 会直接显示提前退出的错误，并给出运行目录内 `host-startup.log` 的位置。Windows 本地构建若报“拒绝访问”，请检查 EXE 是否继承了 Low 完整性标签：该标签会使普通终端启动的程序也无法写入正常 AppData。构建目录标签的修正步骤见 `docs/DEVELOPMENT.md` 的 Windows 完整性说明；不要通过放宽 AppData 权限来处理。

终端账号授权、收藏操作和跨设备遥控尚未实现。Flutter GUI 的频谱与 TUI 分开实现；Linux GUI 共享宿主模式仍保持静态，Windows GUI 保留系统输出频谱。其他平台限制和验收要求见源码仓库的 `docs/DEVELOPMENT.md`。内置 MP3 解码器的 CC0 许可证随终端包放在 `licenses/minimp3/LICENSE`。
